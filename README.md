# Graph Explorer 📈

An interactive graphing tool that teaches relationships between algebraic equations and their visual representations.

## Features
- Interactive parameter sliders for Linear, Quadratic, Exponential, and Trigonometric functions.
- Automated analytical calculations (intercepts, roots, turning points, gradients) powered by SymPy & NumPy.
- Interactive Plotly visualizations.
- "Match the Graph" challenge mode with score feedback.
- Teacher resource & worksheet generator (PDF download).

## Quick Start
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   streamlit run app.py
   ```
